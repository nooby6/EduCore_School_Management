# assets/

Place your school logo, images, and icons here.

Suggested files:
- `logo.png`       — School logo (used in sidebar/login)
- `favicon.ico`    — Browser tab icon
- `hero.jpg`       — Login background image (optional)

To add a favicon, add this inside `<head>` in `index.html`:
```html
<link rel="icon" type="image/png" href="assets/favicon.ico">
```
